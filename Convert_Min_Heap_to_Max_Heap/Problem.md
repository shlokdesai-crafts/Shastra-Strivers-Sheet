# Convert Min Heap to Max Heap

## Problem Statement
Given an array of integers representing a min-heap, convert it into a max-heap in-place.

---

## Input Format
A single line containing space-separated integers representing a min-heap

## Output Format
Space-separated integers of the resulting max-heap

---

## Constraints
- $1 \le N \le 10^5$
- $-10^5 \le \text{val} \le 10^5$
