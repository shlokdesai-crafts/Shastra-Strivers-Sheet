# Build Heap from a Given Array

## Problem Statement
Given an arbitrary array of integers nums, convert it in-place into a binary min-heap in O(N) time.

---

## Input Format
A single line containing space-separated integers nums

## Output Format
Space-separated integers of the resulting min-heap array

---

## Constraints
- $1 \le N \le 10^5$
- $-10^5 \le \text{val} \le 10^5$
