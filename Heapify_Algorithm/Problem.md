# Heapify Algorithm

## Problem Statement
Given an array nums representing a min-heap, set the value at index ind to val and perform heapify to restore the min-heap property.

---

## Input Format
Line 1: space-separated integers nums
Line 2: two integers ind val

## Output Format
Space-separated integers of the array after heapify

---

## Constraints
- $1 \le N \le 10^5$
- $-10^5 \le \text{val} \le 10^5$
