# Minimum and Maximum in Binary Search Tree

## Problem Statement
Given the root of a Binary Search Tree (BST), find the **minimum** and **maximum** values present in the tree.

---

## Input Format
- A single line containing the space-separated level-order traversal of the BST with `null` representing empty nodes.

## Output Format
- Two space-separated integers representing the minimum and maximum values respectively.

---

## Constraints
- $1 \le \text{Number of nodes} \le 10^5$
- $-10^5 \le \text{Node.val} \le 10^5$

---

## Examples

### Example 1
```text
Input:
5 3 8 2 4 7 9

Output:
2 9
```
