# Implement Max Heap

## Problem Statement
Implement a MaxHeap supporting insert, getMax, extractMax, heapSize, and isEmpty operations.

---

## Input Format
Line 1: Integer Q
Next Q lines: operations (insert x, getMax, extractMax, heapSize, isEmpty)

## Output Format
Output of each query that produces a return value

---

## Constraints
- $1 \le N \le 10^5$
- $-10^5 \le \text{val} \le 10^5$
