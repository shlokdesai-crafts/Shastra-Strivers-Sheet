# Heap Sort

## Problem Statement
Given an array of integers nums, sort it in ascending order using the Heap Sort algorithm in O(N log N) time and O(1) auxiliary space.

---

## Input Format
A single line containing space-separated integers nums

## Output Format
Space-separated integers sorted in ascending order

---

## Constraints
- $1 \le N \le 10^5$
- $-10^5 \le \text{val} \le 10^5$
