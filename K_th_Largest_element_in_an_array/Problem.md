# Kth Largest Element in an Array

## Problem Statement
Given an integer array nums and an integer k, return the kth largest element in the array using a Min-Heap.

---

## Input Format
Line 1: space-separated integers nums
Line 2: integer k

## Output Format
A single integer denoting the kth largest element

---

## Constraints
- $1 \le N \le 10^5$
- $-10^5 \le \text{val} \le 10^5$
