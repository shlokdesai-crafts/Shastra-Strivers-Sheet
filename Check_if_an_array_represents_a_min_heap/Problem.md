# Check if an Array Represents a Min Heap

## Problem Statement
Given an array of integers nums, determine whether it satisfies the min-heap property.

---

## Input Format
A single line containing space-separated integers nums

## Output Format
true if min-heap, otherwise false

---

## Constraints
- $1 \le N \le 10^5$
- $-10^5 \le \text{val} \le 10^5$
