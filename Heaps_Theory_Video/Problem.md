# Heaps (Theory & Indexing)

## Problem Statement
Given an array representation of a binary tree of size N and an index ind (0-based), determine:
1. Parent index (or -1 if root)
2. Left child index (or -1 if out of bounds)
3. Right child index (or -1 if out of bounds)

---

## Input Format
Line 1: space-separated integers representing the array
Line 2: integer ind

## Output Format
Three space-separated integers: parent left right

---

## Constraints
- $1 \le N \le 10^5$
- $-10^5 \le \text{val} \le 10^5$
